## The question

Does the generative **process** fill the host's packing budget?

\[
\eta=\frac{\beta}{c\,h_{\mathrm{pack}}}.
\]

The state equation is the equality case \(\eta=1\) in an isotropic
hyperbolic host, with \(c\) declared. It is not a fit of \(\kappa\) to a
sequence tree.

A second, stronger bet (do not run it first): the tape's clock — neighbor
degree, \(\log_2 k\), already in hand on DNA / protein / phoneme — equals
the host's packing clock. That is “curvature set by rate,” and it is
illegal until the host clock is a process metric.

## The gate (all four)

1. **Host of the process.** E9 passed, or \(\eta\) is unlabeled rehearsal.
2. **Growth class exponential** on that same metric. Otherwise
   \(h_{\mathrm{pack}}=0\) by Corollary 4.3 and \(\eta\) is undefined.
3. **Independent clocks.** \(\beta\) from a process clock that is not the
   representation; \(h_{\mathrm{pack}}\) from the representation. Mixed
   cell held out or stratified — do not average quiet tape with lying tape.
4. **Magnitude.** M3 reports a number only when certified. Until then,
   \(\eta\) within \(\pm 20\%\) of 1 is not a result. The growth-class
   gate is not a substitute for a magnitude.

## If it lands

The state equation returns as an **equality at a named host**, not as a
curvature of life. Then, and only then, \(\bar\kappa\) is set by the
packing rate in a declared unit. Paper II's instance is untouched: genomes
still encode the process; the tape still fails quietly or wrongly. IIb
adds whether the process spends the room the limit says it needs.

## If it misses

The bound stands. \(\eta<1\) in a hyperbolic host is utilization slack
(Theorem 4.4), not a tax. On the tape at depth the same gap may be tax —
that is the ladder, already Paper II. A miss here does not unwind the
instance.
