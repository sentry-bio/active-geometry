# TriangleCCS Constitution

This repository is a **geodetic decoder datum** for a tree-structured source
recorded on an overwriting tape. It is not a globe of life, not a language
model, and not a second copy of Active Geometry's Lean spine.

Theorems live in [active-geometry](https://github.com/sentry-bio/active-geometry)
(see that repo's theory/THROUGHLINE.md). Biosphere Atlas is a **consumer**: it registers onto
this form. It does not define the form.

Saturation and curvature genericity are overlays. They are never fields on
`Form`.

## Six clauses

1. **Limit.** Addresses are ε-separated points in a pointed metric space.
   Capacity is packing. No curvature in this layer.

2. **Ladder.** Block distinguishability and genealogy are different witnesses.
   Sequence metrics (JC, Hamming, Mash, and kin) must not supervise topology.

3. **Classifier.** Quartets diagnose tree-ness. They do not set κ, n, or η.
   Unresolved quartets are not the same as confidently wrong quartets.

4. **Chart.** Inhabit polar \(\mathbb H^2\). Dimension two is construction
   (embeddability floor). κ is a frozen **CONVENTION** (InfoNCE gauge), not
   \((h\ln 2)^2\). Radius is a named proxy and remains advisory. Polar
   \((r,\theta)\) is a modelling choice.

5. **Occupation.** Biology lives on the tape. This repo is the decoder.
   Equality (state equation) and curvature genericity are overlays, not form
   parameters.

6. **Honesty.** Every public number is tagged
   `THEOREM | CONVENTION | INSTRUMENT | EMPIRICAL | CANDIDATE | ADVISORY`.
   No silent promotion. No public API path from `(h, kappa)` to `n`.

The encoder of this datum is a **sextant** (named distances onto the chart),
not a genomic language model. See `docs/ENCODER.md`.

## What v1 does not ship

State-equation legend, LUCA-at-origin, live κ from a language model,
Voronoi-as-theory, substrate table, Hyena/129D model sources, Lean sources
(cite Active Geometry).

## Freeze and versioning

Changing κ, tokenizer, anchors, or ε requires a new `Form.version` and a
published transform from the previous epoch. Warm-start inheritance is tagged
`CIRCULAR` and cannot satisfy the freeze-gate alone.
